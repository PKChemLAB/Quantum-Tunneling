# Quantum Tunneling

An educational repository containing interactive Jupyter notebooks for understanding quantum mechanical phenomena, specifically focusing on quantum tunneling and potential wells.

## Overview

This project provides structured learning materials and computational simulations for quantum mechanics concepts, built around Prof. Wang Linjun's educational framework. The repository includes detailed implementations and visualizations of quantum tunneling effects and infinite potential well systems.

## Contents

- **Quantum Tunneling Notebook** (`量子隧穿.ipynb`)
  - Comprehensive exploration of quantum tunneling effects
  - Interactive visualizations and simulations
  - Mathematical foundations and practical examples

- **Infinite Potential Well Notebook** (`无限深势阱.ipynb`)
  - Analysis of particle behavior in infinite potential wells
  - Energy level calculations and wave function visualizations
  - Quantum mechanical problem-solving techniques

- **Visualization Module** (`mydraw.py`)
  - Custom plotting and visualization utilities
  - Helper functions for creating publication-quality diagrams
  - Integration with Jupyter notebooks

## Technology Stack

- **Language**: Jupyter Notebook / Python
- **Primary Tools**: NumPy, Matplotlib, SciPy
- **Format**: Interactive notebooks with embedded computations
